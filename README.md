# DevFlow

DevFlow is a complete React + Vite developer productivity workspace.

## Features
- Dashboard with real project/task/focus statistics
- Project CRUD, filtering, sorting and project details
- Task management synchronized with projects
- Developer notes with tags, pinning, editing and deletion
- Functional 25-minute focus timer with persisted sessions
- Public GitHub profile, repository, language and activity integration
- Seven-day focus analytics
- Dark/light theme
- Responsive mobile navigation
- localStorage persistence
- No Next.js, Supabase, database or backend

## Run
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
npm run preview
```

GitHub data is read from public API endpoints and no token is stored.
